# Book2EPUB — أداة تحويل كتب الويب إلى صيغة EPUB

برنامج Python احترافي ومتقدم مخصص لاستخراج الكتب والموسوعات العربية من مواقع الويب (بدءًا من موقع مكتب سماحة المرجع الديني الأعلى السيد علي الحسيني السيستاني `sistani.org`) وتحويلها تلقائيًا إلى ملفات **EPUB 3** قياسية عالية الجودة، متوافقة تمامًا مع قارئات الكتب الإلكترونية على الهواتف الذكية (Apple Books, KOReader, Moon+ Reader) وأجهزة الكمبيوتر (Thorium, Calibre) وقارئات الحبر الإلكتروني (Kindle, Kobo).

---

## 🌟 المميزات الرئيسية

1. **الالتزام الكامل بالنص الأصلي**:
   - لا تعديل، ولا إعادة صياغة، ولا حذف، ولا تلخيص.
   - الحفاظ على الحركات والتشكيل وعلامات الترقيم كما هي في المصدر.
   - الحفاظ التام على أرقام المسائل وعناوين الأبواب والفصول.

2. **دعم اللغة العربية ومعايير W3C**:
   - ترميز **UTF-8** نقي.
   - اتجاه القراءة من اليمين إلى اليسار (**RTL**) على مستوى المستند والغلاف والتنقل (`page-progression-direction="rtl"`).
   - خطوط عربية واضحة ومريحة للقراءة مع تباعد أسطر مدروس.

3. **هيكلية EPUB نظيفة وقياسية**:
   - ملف `mimetype` غير مضغوط في مقدمة الأرشيف.
   - وثيقة تنقل حديثة `OEBPS/nav.xhtml` متوافقة مع **EPUB 3**.
   - فهرس رجعي `OEBPS/toc.ncx` متوافق مع قارئات **EPUB 2**.
   - فهرس داخلي هرمي قابل للنقر بنسبة 100% يتيح الانتقال الفوري لأي باب أو مسألة.

4. **استبعاد زوائد وشوائب الموقع**:
   - إزالة القوائم العلوية، شريط البحث، روابط المشاركة الاجتماعية، التذييل، والنصوص البرمجية (`<script>`, `<style>`, `<iframe>`).

5. **إدارة متقدمة للـ Cache**:
   - كاش ذكي للـ HTML والصور في مجلد `cache/` لتفادي إعادة التنزيل عند إعادة البناء أو التطوير.
   - دعم الوضع غير المتصل بالإنترنت (`--offline`).

6. **احترام خادم الموقع (Polite Web Scraping)**:
   - مهلة فاصلة ذكية قابلة للتعديل (`--delay`).
   - تنويع عشوائي (Jitter) لتجنب الأنماط الآلية الصارمة.
   - التحقق من ملف `robots.txt`.
   - محاولات إعادة تلقائية مع تراجع أسي (Exponential Backoff) عند بطء الخادم.

7. **حماية النطاق واكتشاف الصفحات**:
   - الزحف يقتصر بدقة على نطاق الكتاب المطلوب ولا يتجاوزه.
   - اكتشاف الصفحات المكملة عبر روابط "التالي" تلقائيًا.
   - نظام منع تكرار الروابط وتطبيعها (Normalization).

8. **التحقق الآلي عبر EPUBCheck**:
   - فحص دوري للملف المخرج عبر أداة **W3C EPUBCheck 5.4.0** للتأكد من خلوه من أي أخطاء برمجية أو قياسية.

## 🚀 التثبيت والمتطلبات

### 1. المتطلبات الأساسية
- **Python 3.10+**
- **Java Runtime Environment (JRE 11+)** *(اختياري لتشغيل أداة EPUBCheck)*

### 2. تثبيت المكتبات
افتح الطرفية (Terminal / PowerShell) في مجلد المشروع ونفّذ:

```bash
pip install -r requirements.txt
```

## 💻 طريقة الاستخدام

### 1. تحويل كتاب واحد
لاستخراج كتاب وتحويله إلى EPUB:
```bash
python main.py "https://www.sistani.org/arabic/book/13/"
```

### 2. تحديد طريقة التقسيم (حسب الباب أو لكل صفحة ويب)
- **التقسيم حسب الأبواب الرئيسية (`--split-mode part`)**: الخيار الافتراضي، يجمع فصول كل باب رئيسي (مثل الطهارة، الصلاة) في ملف واحد لتصفح سلس وسريع.
- **التقسيم لكل صفحة ويب (`--split-mode page`)**: ينشئ ملف XHTML منفصل لكل صفحة ويب تمامًا كما في الملف المرجعي.

```bash
python main.py "https://www.sistani.org/arabic/book/13/" --split-mode page
```

### 3. إعادة البناء السريعة من الكاش (بدون اتصال بالإنترنت)
أثناء التطوير أو لتغيير خيارات التنسيق دون إعادة تنزيل الموقع:
```bash
python main.py "https://www.sistani.org/arabic/book/13/" --offline
```

### 4. تحديث الكاش وإعادة التنزيل
```bash
python main.py "https://www.sistani.org/arabic/book/13/" --refresh
```

### 5. تخصيص مجلد المخرجات أو اسم الملف
```bash
python main.py "https://www.sistani.org/arabic/book/13/" -o "output/al-montakhab.epub"
```

### 6. ضبط المهلة بين الطلبات (احترام الخادم)
```bash
python main.py "https://www.sistani.org/arabic/book/13/" --delay 2.0
```

### 7. استخراج جميع الكتب في قائمة تصنيف (`--all`)
```bash
python main.py --all "https://www.sistani.org/arabic/book/fatwa/"
```

## 🛠️ كيفية إضافة موقع جديد (SiteAdapter)

تم تصميم البرنامج وفق مبدأ **Open/Closed**:
لا تحتاج لتعديل كود البناء أو الزحف لإضافة موقع جديد؛ يكفي فقط:
1. إنشاء ملف جديد داخل `adapters/` (مثل `adapters/my_site.py`).
2. الوراثة من `SiteAdapter` وتنفيذ الدوال التالية:
   - `can_handle(url)`
   - `extract_book_scope(url)`
   - `extract_book_info(html, url)`
   - `extract_page_content(html, url)`
   - `extract_next_url(html, current_url)`
3. تسجيل المحول في `adapters/registry.py`.

## 📊 التحقق من جودة وصحة الكتاب

يقوم البرنامج تلقائيًا بعد كل عملية إنشاء بتشغيل أداة **W3C EPUBCheck** الرسمية وطباعة تقرير مفصل:
- عدد ملفات XHTML.
- عدد الصفحات المستخرجة.
- عدد الصور والغلاف.
- الحجم الإجمالي.
- نتيجة فحص EPUBCheck (التحقق من سلامة XML, OPF, NCX, NAV, CSS).
